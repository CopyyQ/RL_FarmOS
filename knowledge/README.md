# FarmOS Persistent Knowledge

The canonical persistent project memory is:

- `knowledge/START_HERE.md`

Before continuing model development, benchmarking, training, reward design, route logic, market logic, or portfolio logic, read `START_HERE.md` first.

When new evidence disproves an old conclusion, edit `START_HERE.md` so there is one current source of truth. Move the disproved idea into the rejected/superseded section with the benchmark evidence.

Do not treat experimental worktrees as canonical unless their changes have been validated and promoted to `farmosv1`.
